# Stratavell v0.1.2

A packaging release. The engine is the same as in v0.1.1. What's new is easier ways to install and integrate it.

## New

- **Docker image** `ghcr.io/tobiaslogic/stratavell`, for linux/amd64 and linux/arm64. It is static, runs as non-root and is about 25 MB. Its default command is the MCP server over stdio, with the archive in the `/data` volume:
  ```bash
  docker run -i --rm -v stratavell-data:/data -e STRATAVELL_SESSION=my-project ghcr.io/tobiaslogic/stratavell:0.1.2
  ```
  Serving HTTP from the container needs a bearer token, as it does everywhere else on a non-loopback address.
- **MCP Registry entry** `io.github.TobiasLogic/stratavell`.
- **Python client**, `pip install stratavell`. It uses the standard library only and talks to the server over TCP or a Unix socket.
- **TypeScript client**, `npm install stratavell`. It has no runtime dependencies, ships type definitions and uses the global `fetch` (Node 18 or newer, Deno, Bun, browsers).

The clients are thin wrappers over HTTP API v1. The wire format is stable within 0.x, and the client method names may still change (see `docs/stability.md`).

## Unchanged

The engine, the HTTP API, the MCP tools, the database schema and the configuration are the same as in v0.1.1. The benchmark results and search latency figures from v0.1.1 still apply.

## Install

```bash
go install github.com/TobiasLogic/stratavell/cmd/stratavell@v0.1.2
```

Or use the archives below, verified against `SHA256SUMS`, or the Docker image.
