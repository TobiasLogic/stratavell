# Stratavell v0.1.3

A security patch release. Upgrade if more than one session or agent shares a Stratavell database.

## Security

- **`memory_get_summary_lineage` returned summaries the agent could not see.** It checked access only for event ids. Given a summary id from another session, or from a sibling sub-agent in the same session, it returned that summary's structure:
  - kind, level and sequence range
  - the number of source events
  - the ids of its child and covering summaries

  It returned no summary text and no event content.
  - **Affected:** v0.1.2 and earlier, through the Go SDK, HTTP, the Unix socket and MCP.
  - **Exposure:** the caller has to already know the id of a summary it cannot see. An HTTP or socket token reaches every session by design, so the bug matters most for agents limited to one session, and for sub-agents.
  - **Fix:** such a summary now gets the same "not found" reply as one that does not exist. Child and covering-summary lists leave out summaries the agent cannot see.
  - Found by a cross-session probe during the LOCA-bench agent test.
- **`memory_expand` showed that a hidden summary exists.** It refused such a summary with a different message than a missing one. Both now get the same reply, and it leaves out child summaries and events the agent cannot see.
- Regression tests cover the engine, the HTTP API and the MCP server, across sessions and between sibling sub-agents.

## Also in this release

Benchmark harness and documentation fixes, none of which change the engine:
- The standing-rule visibility keys no longer match ordinary session text. The corrected results are in `docs/benchmarks.md`.
- The reader test has `-reader-only` and `-reader-dry-run`, and its strict grade is labeled "strict correct".

The full list is in `CHANGELOG.md`.

## Unchanged

The HTTP API, the MCP tool set, the database schema and the configuration are the same as in v0.1.2. The 64K main, matched and ablation suites reproduce the published results.

```bash
go install github.com/TobiasLogic/stratavell/cmd/stratavell@v0.1.3
```

Or use the archives below, verified against `SHA256SUMS`, or `ghcr.io/tobiaslogic/stratavell:0.1.3`. The clients are `pip install stratavell` and `npm install stratavell`.
