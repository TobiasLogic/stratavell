# Stratavell v0.1.0: Research Preview

Stratavell is a provider-agnostic context management engine for long-running LLM agents, written in Go:
- asynchronous progressive compaction
- losslessly retrievable history in an immutable SQLite journal
- cache-aware context assembly
- persistent, provenance-aware task state

It runs fully locally as a Go library, an HTTP API over TCP or a Unix socket, an MCP server and a single static binary.

This is the first public release and a research preview. The Go API, HTTP API and storage format may change before 1.0 (see `docs/stability.md`).

## Preliminary results

Measured on generated 300-turn coding sessions with a 64k-token window and 5 seeds. Costs are simulated input costs at Claude Sonnet 5.5 prices, from a model of Anthropic's prompt-cache rules.

| strategy | simulated input cost per session | facts recoverable | standing rules visible |
|---|---|---|---|
| async progressive summaries + retrieval | $12.88 | 97.2% | 21.9% |
| Stratavell | $6.43 | 100% | 100% |

- **Cost:** about half the simulated context cost of retrieval-enabled asynchronous progressive summarization, at comparable fact recoverability.
- **Real-model QA:** a pre-registered run (Claude Haiku 5.5, 33 questions, 1 seed) was a tie with the component-matched baselines: 28, 27 and 26 grounded answers.
- **Not measured:** real autonomous coding-task success and instruction compliance. The baselines are reconstructions.

The full method, every table and the limitations are in `docs/benchmarks.md` and `docs/limitations.md`.

## Install

```bash
go install github.com/TobiasLogic/stratavell/cmd/stratavell@v0.1.0
```

Or download an archive below. Linux, macOS and Windows on amd64 and arm64 are cross-compiled with `CGO_ENABLED=0`. Verify downloads with `SHA256SUMS`.

Platform testing for this release:
- **Linux amd64:** the full suite passes, including the race detector, the crash-recovery test, fuzzing and the cross-language examples.
- **macOS arm64:** CI passes.
- **Windows amd64:** CI passes every package except one store test that uses a `?` in a directory name, which Windows does not allow. The test was fixed on `main` after the tag, and the engine code is unaffected.
- **Other platforms:** the remaining builds are cross-compiled but untested.

## Upgrading from palimpsest

The project was developed as palimpsest. See "Migrating from palimpsest" in `docs/operations.md`. The schema is unchanged, `PALIMPSEST_*` variables still work with a warning, and `stratavell migrate` copies a database to the new default name without touching the original.

See `CHANGELOG.md` for the complete list of changes.
